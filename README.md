Each token looks at every other token in the sequence to decide which ones matter for understanding it. Every token produces three vectors:

Query (Q): what I’m looking for
Key (K): what I offer
Value (V): the information I carry

A token’s Query is compared against all Keys to produce attention scores, which are then used to take a weighted mix of the Values. In “The animal didn’t cross the street because it was tired,” attention lets “it” draw heavily from “animal.”

Multi-Head Attention

Instead of one attention calculation, the model runs several in parallel (the original used 8 heads), each with its own learned Q/K/V projections. Different heads can specialize: one tracks grammar, another tracks pronoun references, another tracks nearby words. Their outputs are concatenated and combined.

Positional Encoding

Attention processes all tokens at once, so it has no built-in sense of word order (“dog bites man” vs. “man bites dog”). Positional encodings are added to the embeddings to inject position information. The original paper used fixed sine and cosine patterns; many modern models use learned or rotary (RoPE) variants.
